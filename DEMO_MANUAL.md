## Passo 2 — Dashboard do Fornecedor

Após o login você vê o painel principal. Destaque para o público:

2. Mostre a lista de documentos exigidos pelas categorias do fornecedor
3. Destaque os diferentes tipos de documentos:

> Diga ao público: *"A ELOS elimina o trabalho manual de coletar certidões.
> Tudo que pode ser automatizado, é automatizado."*

# Perguntas Frequentes do Público

**"Como o fornecedor sabe que foi homologado?"**
> Recebe um e-mail automático e o painel muda para Selo Ativo. O score fica visível no marketplace.

**"E se o documento vencer depois da homologação?"**
> O Farol de Documentos alerta o analista. O fornecedor é notificado. O analista pode suspender o Selo até a renovação.

**"O cliente vê os documentos do fornecedor?"**
> Sim — vê o status de cada documento (Válido / Pendente / Vencendo), mas não baixa o arquivo. A análise é feita pela EQPI.

**"Como funciona o questionário customizado?"**
> O admin cria as perguntas vinculadas a um cliente específico. O fornecedor responde no painel. As respostas ficam visíveis para o analista na fila de análise.

**"Quantas categorias um fornecedor pode ter?"**
> Múltiplas. Cada categoria exige um conjunto de documentos. O sistema consolida tudo automaticamente.

**"O que é subsidiado?"**
> O cliente pode assumir o custo da homologação do fornecedor (plano anual). O campo fica marcado no convite e visível no painel do cliente.
